# Icone condivise fAInance

Grafica ricavata dal font di sistema del Samsung Galaxy A55 di riferimento, con i suoi font emoji di fallback. PNG locali da 72 px identici su web, Android e WidgetKit; nessuna grafica Twemoji.

Provenienza e licenza OFL 1.1 in public/fainance-icons/. Il parser Unicode preesistente conserva la propria licenza MIT. Le icone personali restano dati dell’utente.

Il runtime, i selettori e la sincronizzazione restano invariati. Archivia e Ripristina usano le cartelle originali anche sul web. npm run check:icons verifica copertura e uguaglianza delle copie native. La verifica non equivale a un collaudo fisico iOS.
